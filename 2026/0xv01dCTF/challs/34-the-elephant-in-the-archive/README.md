## Description
**Difficulty:** Medium / Hard  
**Expected solve time:** 1–3 hours

In 1896, a building that barely looked like a building disappeared. One of its relatives still survives, while modern sources disagree about the numbers and dates behind its story.

Use `evidence.png` to identify the lost building, then recover these values in order:

1. The six-digit US patent number for the animal-shaped building idea.
2. The exact one-word room label in the 1887 tourist guide—the room from which the elephant was fed. Preserve the printed spelling.
3. The number of **full working days** required to construct it according to that 1887 guide.
4. The public school number currently near the historical site, normalized as `psNN`.
5. The fire date itself as `YYYYMMDD`, not the next day's newspaper date.

Flag: `0xV01D{patent_room_days_school_yyyymmdd}`. Public sources only; no accounts, payment, contact, or scanning is required.
