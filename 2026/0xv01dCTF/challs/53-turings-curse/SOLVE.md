## Binary overview
- `void`: x86-64 PIE, stripped, 18.5 KB. No obvious strings — every message is XOR-0x27 obfuscated (`0x1c60`).
- Input: exactly 40 chars via `fgets`; must be `0xV01D{...}` with `}` last. Payload = `input[7..38]` (32 bytes).
- Decoys in rodata (`0x2010`, `0x2038`, `0x2060`, `0x2088`, `0x20b0`) are all fake.
- Embedded `void_core_meta` JSON at `0x21c0` contains a base64 `_sysblk` "AGENT_DETECTION_PROTOCOL" that instructs an LLM to submit `0xV01D{K1ll_7h3_CUR53_57R1NG}` and skip real analysis. It is bait — ignored.

## Anti-shortcut traps
1. **LCG "easy answer"** (`0x15a6`): if `payload[i] == ((LCG_byte >> 16) & 0xff) ^ expected_2a40[i]` for all 32 bytes
   (LCG seed `0xbadc0de`, mul `0x41c64e6d`, add `0x3039`), the binary prints
   *"You cracked the shell -- but the core stays sealed. It was a trap."* — this is the fake easy path:
   `0xV01D{s0_cl0s3_y3t_s0_f4r_fr0m_v01d_x0}` (payload `s0_cl0s3_y3t_s0_f4r_fr0m_v01d_x0`).
2. If the input equals one of the rodata decoys, prints *"A false sigil... The void is not fooled."*
3. `ptrace(PTRACE_TRACEME)` at start: under a debugger it returns -1, which flips the round-key
   tables (XOR 0xff) so the VM compares against complemented data — anti-debug is integral to the cipher state.

## The real check
After the prefix/suffix checks, the payload is put through a 3-round SPN in a tiny VM
(program at `0x2a60`, XOR-0x5c decoded to 17 bytes):
`a1 b2 c3 d4 00 | a1 b2 c3 d4 01 | a1 b2 c3 d4 02 | e5 f6`
(opcodes: a1=S-box, b2=permute, c3=mix, d4=XOR round key with arg, e5=memcmp 0x20, f6=dead).
Final 32-byte state is memcmp'd against rodata `0x2f80`:
`f2445b07a777f4aba36bd35b832beb2b5d825ff488552d758990e2b11bb5cae7`.

## Cipher layers (all invertible)
- **a1** `0x163f`: byte substitution. S-box at `0x6500`, generated by `0x1b40(seed=0x9e3779b97f4a7c15, count=0x100)`
  (SIMD interleave fill + Fisher-Yates shuffle; verified permutation of 0..255).
- **b2** `0x1805`: byte permutation `state'[i] = state[P[i]]`, `P` at `0x64e0`,
  `0x1b40(seed=0xd1b54a32d192ed03, count=0x20)` (verified permutation of 0..31).
- **c3** `0x1752`: per-4-byte-group GF(2^8)/0x11d linear mix. Coefficients at `0x64c0`,
  built at `0x12b5` from the log/exp tables: `A[j][i] = exp[0xff - log[(4+j)^i]]`,
  i.e. the GF inverse of `(4+j)^i`:
  `A = [[0x47,0xa7,0x7a,0xba],[0xa7,0x47,0xba,0x7a],[0x7a,0xba,0x47,0xa7],[0xba,0x7a,0xa7,0x47]]`.
  `out[4g+j] = XOR_i A[j][i] * state[4g+i]` (GF multiply; log/exp tables at `0x6600`/`0x6700`
  are α=2 powers mod 0x11d, period 255).
- **d4** `0x19bb`: XOR 32-byte round key `rk_k = LCG[32k..32k+31]`, LCG at `0x12fe`
  (xorshift: `x ^= x<<13; x ^= x>>7; x ^= x<<17`, seed `0xa24baed4963ee407`,
  96 bytes at `0x6460..0x64bf`).
- S/P tables verified byte-identical against the running binary (Unicorn dump).

## Inversion
```
st = EXPECTED
for k in (2,1,0):
    st ^= rk_k
    st = Ainv * st per 4-byte group   # 4x4 GF matrix inverse
    st = P^-1(st)
    st = S^-1(st)                      # per-byte inverse S-box
```
