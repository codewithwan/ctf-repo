## 🇬🇧 English

The largest bee marketplace opened a beta cabinet, B2Bee, for its partners. Sellers can upload Java plugins that compute discounts and bonuses for carts of hive goods.

Before launch, a review-bee peeks into each JAR. She insists she can recognize any dangerous plugin before it runs, and the plugin itself executes in a separate quarantine cell.

Get the honey-badger past review and obtain the bees' main secret (also known as the file **/flag.txt**).

## 🇷🇺 Original (Russian)

Крупнейший пчелиный маркетплейс открыл партнёрам бета-кабинет B2Bee. Продавцы могут загружать Java-плагины, которые рассчитывают скидки и бонусы для корзин с товарами из улья.
